## 지켜야 할 약속
1. PERFECT로 친 키음 = 반주와 같은 샘플 (CP1·CP2 기록 시계 C = 장치 시계 + D, 키음 목표 = 누른 순간 프레임 + D).
2. 실시간 스레드(오디오 콜백·판정)는 할당·잠금·파일 작업을 하지 않는다. 판정은 순수 함수(같은 입력 순서·watermark면 같은 결과).
3. 미리보기 = PERFECT 플레이의 소리, 탐색은 플레이와 같은 코드, 준비 부족은 건너뛰지 않음, 취소된 늦은 작업은 게시하지 않음.
4. 판정·게이지는 데이터(`Rules`)로 다뤄 CP4 커스텀이 코드 수정 없이 얹히게.

## 요청 (우선순위 순)
1. **정확성 버그**: 믹서(나눠 섞기 경계, 끊기·choke와 예산의 상호작용, seek와 fill의 경계 프레임, pause 시 pending·cursor·ready_cursor 처리, i16 경로), 판정(노트 고르기·빈 POOR·롱노트 끝·지뢰·watermark 확정 순서·같은 레인 여러 키·키 반복), 게이지 수식(표·바닥·생존형·EASY 0.8 절사·HARD 1666), 로더(변형 선택·쓰지 않는 소리 슬롯·프레임 수 예측과 실제 디코딩 길이 불일치·i16 판정), 미리보기 저장소(경쟁 상태, 공유 디코딩 결과 수명, 취소, 순서).
