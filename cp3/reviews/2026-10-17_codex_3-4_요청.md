## 단계 목표와 완료 기준
1. CP3 설정 전부를 화면에서 바꾸고 다시 켜면 그대로 복원(범위별). 손으로 고친 파일·깨진 파일도 기본값으로 안전하게.
2. 규칙 해시가 meta.json·결과·리플레이에 있고, 리플레이가 규칙 해시로 비교를 거른다.
3. 보정 도구 둘이 봇 오프셋을 ±1 ms로 되찾는다(직접 입력 모드).
4. 오프셋 A: 정박에 친 봇은 판정 오차 = A, 키음 = 반주 + A. A를 보정해 PERFECT로 친 봇은 키음 목표 = 반주 자리. B는 판정·소리 불변.
자체 확인(재현하지 말고 코드로 판단): 봇 +20 ms → 소리 보정 중앙값 +20.0(MAD 0) → 제안 A −20, 화면 보정 → B + 20. 선곡 → F1 → 보정 → 적용 → 저장 키 스크립트로 `offset_a_ms = -20` 저장. A +10/−8에서 키음 목표 − 반주 자리 = A(0.1 ms 안). A −20 + 늦게 치는 봇 → 81 PG, 키음은 최대 18.8 ms 늦게 바로 재생(늦은 키음 정책).

## 지켜야 할 약속
1. PERFECT로 친 키음 = 반주와 같은 샘플(A = 0일 때). A는 판정과 키음을 함께 옮기고 반주는 옮기지 않는다. 누름 → 소리는 물리 최소.
2. 실시간 스레드(오디오 콜백·판정)는 할당·잠금·파일 작업을 하지 않는다. 판정은 순수 함수.
3. 규칙 해시에는 판정 결과를 바꾸는 값만, 오프셋·음량·D는 넣지 않는다. 같은 규칙이면 어느 PC에서도 같은 해시.
4. 사용자 설정 파일은 "저장"으로만 바뀐다(보정 실행·깨진 값 읽기·임시 파일이 사용자 파일을 덮지 않음, 단 깨진 파일은 `.broken`으로 옮김).
5. 명령줄 인자가 있으면 설정보다 우선, 설정 파일이 없으면 3-3과 같은 기본값.
