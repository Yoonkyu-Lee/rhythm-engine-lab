# CP3 데모: 세 게임의 곡을 하나의 엔진으로

DJMAX·IIDX·BMS 곡을 같은 형식(Track)으로 바꿔, 같은 프로그램에서 고르고 미리 듣고 친다. 레인 수가 달라도 코드는 같고, 키음은 어느 곡에서나 PERFECT면 반주와 같은 샘플에 놓인다.
모든 명령은 `cp3/` 폴더의 PowerShell에서 실행한다 (빌드: `cargo build --release`). 곡 자료(`content/`)는 이 PC에만 있다(비공개).

## 1. 선곡 화면

```powershell
.\target\release\cp3game.exe select content\library
```

| 키 | 하는 일 |
|---|---|
| ↑ ↓ · PgUp PgDn | 곡 (10곡씩) |
| ← → | 차분 |
| Space | 미리보기 켜기·끄기 |
| [ ] · Home | 10초 앞뒤로 탐색 · 하이라이트로 |
| Enter | 플레이 (미리보기에서 디코딩한 소리를 그대로 넘겨받는다 — 불러오기 수십 ms) |
| F1 | 설정 화면 |
| Esc | 끝 |

- 곡 목록은 색인(`index.bin`) 하나만 읽는다(지금 870곡, 약 16 MB, 읽기 22 ms — 실행하고 0.3초면 목록이 뜬다). 아래 막대 = 250 ms 칸 노트 수, 빨간 선 = 미리보기 위치.
- 커서가 150 ms 머물면 그 차분을 **하이라이트부터 키음까지 전부 자동 연주**로 들려준다(머문 150 ms 뒤 보통 0.2~0.35초, 장치 출력 지연 별도). 들을 곳의 소리부터 디코딩하고, 긴 반주 stem은 들을 곳 근처 8초만 먼저 디코딩한다(전체와 비트까지 같음). 준비가 덜 되면 건너뛰지 않고 잠깐 쉬었다 같은 자리에서 잇는다(아래 줄의 "버퍼링" 횟수).
- 탐색해도 처음부터 들은 것과 같은 소리다(같은 소리 끊기·보이스 수까지 다시 계산).

## 2. 플레이

| 키 | 하는 일 |
|---|---|
| 레이아웃별 기본 키 | IIDX·BMS 7+1: 왼쪽 Shift(스크래치) Z S X D C F V · DJMAX 8B: 왼쪽 Shift S D F V N J K L 오른쪽 Shift · 그 밖은 설정에서 |
| F5 | 오토(봇) 켜기·끄기 |
| G | 실시간 싱크 그래프 |
| F1 ~ F4 · + − | 렉 주입 (오디오·화면·판정·입력) · 길이 두 배·절반 (CP2와 같음) |
| Esc | 끝 (곡이 끝나면 저절로) |

해 볼 것:
1. **세 게임의 레이아웃**: DJMAX 8B(레인 10: 건반 6 + L1·R1 + 사이드), IIDX SP(스크래치 + 7), IIDX DP(16), BMS 7K를 차례로. 레인 배치·색·키는 레인 id로 정해지고 하드코딩이 없다.
2. **키음 = 반주**: 오토(F5)를 켜고 키음이 많은 곡(IIDX `Blind Justice` SP ANOTHER, BMS `Taken The First Step`)을 들어 본다. F1(오디오 정지)을 넣어도 다시 붙는다.
3. **랜덤 변형**: BMS 랜더마이저 차분(`_hsgr_randomizer_hexa`)은 칠 때마다 다른 변형(1,000가지 중)이 나오고, 결과의 `variant_choice`로 다시 칠 수 있다(설정의 변형 시드로 고정 가능).
4. **리플레이**: 끝난 뒤 `cp3game replay runs\<폴더>` → 기록한 입력으로 다시 판정해 실시간 점수와 같은지 본다(규칙 해시가 다르면 비교에서 뺀다).

## 3. 설정 (선곡 화면 F1)

| 탭 | 내용 |
|---|---|
| 규칙 | 게이지(NORMAL·EASY·ASSIST·HARD·EX-HARD), 변형 시드, 판정 창 보기, 규칙 해시 |
| 장비와 몸 | 오디오 경로·출력 장치·배타 주기·ASIO 버퍼, D 자동/수동, **오프셋 A**(판정 + 키음), **오프셋 B**(화면), 보정 둘 |
| 소리 | 음량(마스터·반주·친 키음), 늦은 키음 한도, 빈 누름 소리 |
| 입력 | 레이아웃마다 레인 → 키(여러 개, Enter 후 키 누르기, Backspace 비움) |
| 화면 | 노출 시간, 기준 스크롤(곡 필드·시작·최빈·최고·최저) |
| 라이브러리 | 곡 폴더(Enter = 폴더 고르기) |

- **소리로 맞추기 (A)**: 클릭(120 BPM, 40박)을 들으며 박에 맞춰 누른다 → 내 누름의 늦음(중앙값)과 흔들림이 나오고, "적용"을 누르면 A가 그만큼 바뀐다.
- **화면으로 맞추기 (B)**: 소리 없이 노트가 판정선에 닿을 때 누른다 → B 제안.
- S 저장 → `settings.toml`(전역·장치별·키 모드별·프리셋). 다시 켜면 그대로.

## 4. 숫자로 보기 (선택)

- `cp3game run <곡.trk> --chart <id> --bot` 뒤 `python -I -X utf8 tools\analyze_sync.py runs\<폴더>` → PERFECT 키음 vs 반주, 판정·소리 불일치, 도장 − 실제 누름, 녹음 무결성.
- `cp3game select content\library --bench 20` → 미리보기 첫 소리까지 시간 분포.
