# CP3 용어집

CP3 문서·코드·기록에 나오는 말을 한곳에 모았다. 각 항목은 **뜻** → **게임으로 치면** → **어디에**(코드·파일) 순서다.
CP2 용어(기록 시계 C, D, 시간축, 콘텐츠 건너뜀, 입력 도장 등)는 [../cp2/GLOSSARY.md](../cp2/GLOSSARY.md)를 그대로 쓴다. 엔진 이름 "Unison"은 문서에서만 쓰는 임시 이름이다.

## 1. 곡 객체 (Track)

| 용어 | 뜻 | 게임으로 치면 | 어디에 |
|---|---|---|---|
| **Track** | 곡 하나(음악)와 그 곡의 차분들·소리 전부를 담는 곡 객체 | 곡 폴더 하나 | [Track_형식.md](Track_형식.md) |
| **작성 형식** | 사람이 읽고 쓰는 TOML 폴더(`track.toml` + `charts/*.toml` + 소리 파일). 컨버터의 출력 | 채보 원고 | `crates/track/src/source.rs` |
| **실행 형식 · 묶음(.trk)** | 컴파일한 바이너리 파일 하나(구역 + 해시). 같은 입력이면 비트까지 같다 | 게임이 바로 읽는 곡 파일 | `pack.rs`, `trackc compile` |
| **차분** | Track 안의 채보 하나. 자기 이벤트를 전부 화이트리스트로 적는다 | NORMAL·HYPER·ANOTHER | `[charts]` |
| **레이아웃 · 레인 id · 역할** | 차분이 정하는 레인 목록(`K1`, `SC`, `SL` …)과 역할(건반·스크래치·사이드·트리거). 레이아웃 = 레인 id를 이은 서명 | 7+1, 8B, DP | `runtime::Lane`, `keys::layout_key` |
| **변형 · 조건** | #RANDOM 같은 선택지. 이벤트마다 조건(변형 = 값, AND)이 붙고, 플레이 때 하나를 고른다(기록: `variant_choice`) | 랜덤 채보 | `Track_형식.md` 3장 |
| **배속 변형** | 같은 채보를 `time_scale`로 빠르게·느리게 한 차분 | 1.5배속 차분 | `time_scale` |
| **소리 표 · 논리 소리 · 데이터 슬롯** | 차분 안 소리 번호(시작·길이·이득·끊기) / 실제 PCM 칸. 같은 (데이터, 시작, 길이)인 논리 소리끼리 슬롯을 공유 | 키음 목록 | `SoundRef`, `SoundBank` |
| **정규 발음 순서** | 같은 시각 소리들의 순서를 정하는 규칙(어느 PC에서나 같은 소리) | — | 명세 3-4 |
| **스크롤 지도 · 기준 스크롤 · 노출 시간** | 시간 → 화면 위치(박) 지도 / 노출 시간을 정하는 속도(박/분) / 기준 속도에서 노트가 나타나 판정선까지 걸리는 ms | 하이스피드 | `scroll_pos`, `scroll_base`, `visible_ms` |
| **손실 (losses)** | 원본을 그대로 옮기지 못한 것(LN 안 노트, 페달, 레이아웃 밖 노트 …). 차분에 "불완전 변환"으로 남는다 | 변환 경고 | `LOSSES` 구역 |
| **라이브러리 색인** | 곡 묶음을 열지 않고 선곡 화면을 그리는 파일(제목·차분·250 ms 칸 노트 수·하이라이트) | 곡 목록 캐시 | `index.bin`, `trackc index` |

## 2. 소리 저장소와 미리보기 (README 4-3)

| 용어 | 뜻 | 게임으로 치면 | 어디에 |
|---|---|---|---|
| **계획 (Plan)** | 차분 하나를 장치 레이트로 올릴 일 목록(쓰는 소리만, 슬롯 프레임 수 미리 계산, 최고 메모리 추정) | 로딩 준비 | `load::plan_chart` |
| **소리 저장소** | Track 단위로 디코딩한 PCM 슬롯(i16 또는 f32). 차분 사이·미리보기 → 플레이에서 공유, 곡을 바꾸면 버림 | 메모리에 올린 키음 | `SlotCache`, `preview::Store` |
| **준비 집합 · W** | 시작 지점에 울리고 있어야 하는 소리 + 앞으로 W초 안에 시작하는 소리. 다 준비돼야 소리를 낸다 | "들을 곳부터 로딩" | `Store::ready_at` |
| **부분 디코딩 · 부분 슬롯** | 시작 지점에 울리고 있는 긴 Vorbis 소리를 그 근처 8초만 먼저 디코딩한 것. 한 패킷 앞부터 디코딩하고 절대 위치로 리샘플링해 전체 디코딩의 같은 구간과 비트까지 같다. 믹서는 전체 슬롯이 없으면 이것을 읽는다 | 긴 반주를 다 풀기 전에 들을 곳만 먼저 | `Partial`, `decode_slot_partial`, `decode_vorbis_range` |
| **버퍼링** | 재생 중 앞으로 W 안에 준비 안 된 소리가 생기면 건너뛰지 않고 쉬었다가 같은 자리에서 잇는 것 | 스트리밍 영상의 버퍼링 | `Mixer::set_lookahead` |
| **디바운스** | 커서가 이만큼 머문 뒤에야 미리보기 작업을 시작(지금 150 ms) | 휙휙 넘길 때 로딩 안 함 | `select.rs` |
| **세대 번호** | 요청마다 붙는 번호. 곡을 바꾸면 올리고, 낡은 작업은 결과를 게시하지 않는다 | 취소 | `Store::cancel` |
| **탐색 (seek)** | 목표 시각까지 소리를 섞지 않고 보이스 배정만 다시 돌려 같은 상태로 시작 | 진행 바 클릭 | `Mixer::seek` |
| **플레이 인계** | 미리보기에서 디코딩한 슬롯을 플레이가 그대로 받는 것(실행 상태는 넘기지 않음) | 플레이 로딩이 거의 없음 | `game::run_with` |
| **메모리 예산** | 계획의 최고 사용량이 넘으면 시작하지 않는 한도 | — | `BUDGET` |

## 3. 판정·게이지·규칙

| 용어 | 뜻 | 게임으로 치면 | 어디에 |
|---|---|---|---|
| **Rules** | 판정 창(등급별 빠름·늦음 경계 ns)·스크래치 창·빈 POOR·게이지 표를 담은 데이터. CP4 커스텀이 이 위에 얹힌다 | 판정 설정 | `judge.rs` |
| **빈 POOR** | 노트를 고르지 못한 누름 중 가장 가까운 노트가 BAD보다 이르고 350 ms 안인 것 | 공POOR | `Judged::Empty` |
| **LN · CN · HCN** | 끝 판정 없는 롱노트(BMS) / 떼기 판정 있는 롱노트 / CP3은 CN으로 | 롱노트 | `LongRule` |
| **Judge · watermark** | 여러 레인 판정기 / "이 시각까지의 입력은 다 왔다"는 입력 스레드의 표시. 확정 순서를 고정해 리플레이 = 실시간 | — | `judge::Judge` |
| **규칙 해시** | 판정을 바꾸는 값(Rules·롱노트 규칙·재동기화 중 판정 정책)의 BLAKE3. 점수 비교 단위 | "어떤 룰로 친 점수인가" | `game::rules_hash` |
| **리플레이** | 기록한 입력으로 다시 판정해 실시간 점수와 비교 | — | `cp3game replay` |

## 4. 설정과 보정 (3-4)

| 용어 | 뜻 | 게임으로 치면 | 어디에 |
|---|---|---|---|
| **설정 범위** | 전역 · 장치별(`"<경로>:<장치>"`) · 키 모드별(레이아웃 서명) · 프리셋 | 옵션이 어디에 붙나 | `settings.toml`, `settings.rs` |
| **오프셋 A** | 청취 곡 시각에 더하는 값: 판정과 키음이 함께 움직이고 반주는 그대로 | 판정 타이밍 조절 | `out_offset_ns` |
| **오프셋 B** | 노트를 그리는 위치만 옮김(판정·소리 불변) | 화면 싱크 조절 | `display_offset_ns` |
| **소리로 맞추기 · 화면으로 맞추기** | 클릭을 듣고 / 노트를 보고 박에 맞춰 누른 오차의 중앙값으로 A / B를 제안. 측정한 장치에만 적용 | 오프셋 자동 측정 | `calib_ui.rs`, `calib.rs` |

## 5. 측정 (3-5)

| 용어 | 뜻 | 어디에 |
|---|---|---|
| **키음 vs 반주 · 잔차** | PERFECT 키음이 놓인 프레임 − 그 노트 시각의 반주 위치 / 그 값 − 판정 오차(판정이 맞다고 한 만큼 소리도 맞았나) | `tools/analyze_sync.py` |
| **판정·소리 불일치** | \|잔차\| > 1 ms | 〃 |
| **도장 − 실제 누름** | 판정이 쓴 누름 시각 − 봇이 SendInput을 부른 시각 | 〃 |
| **무결성** | 믹서 기록으로 다시 만든 출력(`cp3game restream`) ↔ 루프백 녹음이 곡 내내 같은 어긋남인지 (창마다 그 자리의 건너뜀 offset 반영) | 〃 |
| **OS 입력 봇 · 직접 입력 봇** | SendInput으로 실제 입력 경로를 거치는 봇(`--bot`, 게임 창이 앞일 때만 누름) / 입력 링에 바로 넣는 기능 시험용 봇(`--bot-direct`) | `bot.rs` |
