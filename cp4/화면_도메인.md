# 화면 도메인 — 화면에 나오는 모든 것의 이름

> 상태: **초안 (2026-10-17, CP4 제안)**. 확정 전까지 이름·구조는 바뀔 수 있다. ⚑ = 사용자 판단이 필요한 곳.
> 목적: 사용자가 **화면의 어느 자리에 어떤 에셋(텍스트·영상·이미지·도형)을 연결할지** 정확히 말할 수 있게, 엔진·스킨·문서·코드가 같은 이름을 쓴다.
> 이 문서의 이름이 표준이다. 코드 식별자는 여기의 영문 ID를 그대로 쓴다(엔진 이름 "Unison"은 코드에 쓰지 않는다).
> 참고: Qwilight 화면 요소 14종·스킨 옵션(`../cp0/Qwilight_settings.md`), beatoraja·LR2 스킨(이미지·숫자·글자·막대·그래프 + 위치·타이머·조건), IIDX·DJMAX의 고정 화면.

---

## 0. 한눈에

```
스킨(Skin) ─ 화면(Scene)마다 배치(Layout) ─ 층(Layer) ─ 요소(Element) ─ 자리(Slot)에 붙음
                                                    │
                       에셋(Asset): 그림·영상·글꼴·소리 파일 ┘
요소의 속성 ← 값(Value)·사건(Event)·시계(Clock)로 움직임 (바인딩·애니메이션)
```

- **엔진이 정하는 것**: 화면 목록, 각 화면의 **자리(Slot)** 목록과 그 자리가 받는 요소 종류, 자리에 흘려 주는 **값·사건·시계**.
- **스킨이 정하는 것**: 자리마다 어떤 요소를 어디에 어떤 모양으로 둘지, 어떤 에셋을 쓸지, 값·사건에 어떻게 반응할지, 스킨 자기 옵션.
- **곡(Track)이 정하는 것**: 곡 그래픽(BGA 영상·곡 그림·자켓 등)과 그 시각. 스킨은 곡 그래픽이 들어갈 **자리**를 정할 뿐 내용을 바꾸지 않는다.
- **판정·소리는 화면과 무관**하다. 화면은 엔진 상태를 읽어 그리기만 한다(그리기가 늦어도 판정·소리는 그대로 — CP2·CP3 원칙).

---

## 1. 화면 (Scene)

화면 = 한 번에 하나 앞에 있는 게임 단계. 화면 사이 전환에도 이름이 있다.

| ID | 이름 | 하는 일 | CP3 대응 |
|---|---|---|---|
| `boot` | 시작 화면 | 로고·라이브러리 색인 읽기 | (없음) |
| `select` | 선곡 | 곡 목록·차분·미리보기·통계 | `cp3game select` |
| `decide` | 곡 결정 | 곡을 고른 뒤 로딩 동안 (플레이 인계) | (즉시 플레이) |
| `play` | 플레이 | 기어·노트·판정·게이지 | `cp3game run` |
| `result` | 결과 | 점수·판정 분포·기록 비교·리플레이 저장 | (한 줄 요약) |
| `settings` | 설정 | 설정 체계의 탭 | F1 설정 화면 |
| `calibrate` | 보정 | 소리로 맞추기·화면으로 맞추기 | 보정 실행 |
| `overlay` | 덮개 | 모든 화면 위: 알림·FPS·진단 그래프 | HUD·G 그래프 |

- **전환(Transition)**: `from → to` 사이의 연출(페이드·와이프 등). 이름 `transition.<from>.<to>`, 없으면 `transition.default`.
- **화면 상태(Scene state)**: 화면마다 엔진이 가진 상태(예: `select`의 커서·필터, `play`의 진행). 스킨은 읽기만 한다.

## 2. 층 (Layer)

한 화면 안에서 그리는 순서. 아래에서 위로:

| ID | 이름 | 예 |
|---|---|---|
| `background` | 배경 | 배경 그림·영상, **BGA**(`play`) |
| `stage` | 무대 | 기어(레인·노트·판정선), 선곡 목록 |
| `effect` | 효과 | 노트 폭발, 판정 글자, 키빔 |
| `hud` | 정보 | 점수·콤보·게이지·BPM·시간 |
| `front` | 앞 | 레인 커버·덮개 그림 |
| `overlay` | 덮개 | 알림·진단 (1장 `overlay` 화면의 내용) |

스킨은 층 안의 순서(`z`)를 정한다. 층 사이의 순서는 엔진 고정(⚑ 스킨이 층을 더 만들 수 있게 할지).

## 3. 요소 (Element) — 화면에 나오는 것의 종류

모든 화면 요소는 아래 종류 중 하나다. **사용자가 말하는 "텍스트·영상·이미지·도형"은 앞의 넷이고, 나머지는 그것들을 묶거나 값으로 그리는 특수형**이다.

| ID | 이름 | 그리는 것 | 에셋 | 주요 속성 |
|---|---|---|---|---|
| `text` | 글자 | 문자열 (곡 제목·장르·안내문) | 글꼴(`font`) | 글꼴·크기·색·정렬·줄바꿈·넘침(자름/흐름/줄임표)·외곽선·그림자 |
| `number` | 숫자 | 정수·실수 값 (점수·콤보·BPM·ms) | 글꼴 **또는** 숫자 그림(0~9 낱장) | 자릿수·앞 0·부호·소수 자릿수·자리 고정 |
| `image` | 그림 | 정지 그림, 또는 스프라이트 시트의 한 칸 | 그림(`image`), 시트 | 원본 영역(자르기)·칸 선택·9조각 늘이기·색 곱하기·혼합 방식 |
| `sequence` | 연속 그림 | 그림 여러 장을 시간에 따라 (폭발·판정 글자 애니메이션) | 시트 또는 그림 목록 | 칸 수·초당 칸·반복/한 번·시작 사건 |
| `video` | 영상 | 영상 파일 (BGA·배경 영상·선곡 미리보기 영상) | 영상(`video`) | 재생 시계(곡 시각/화면 시각)·반복·소리 끔·맞추기(채움/맞춤/늘이기) |
| `shape` | 도형 | 사각형·둥근 사각형·선·원·다각형 | (없음) | 채우기 색·그라데이션·테두리·두께·모서리 |
| `bar` | 막대 | 0~1 값을 길이로 (게이지·진행 바·HP) | 그림 또는 도형 | 방향·칸 나누기(2% 눈금 등)·구간별 색 |
| `graph` | 그래프 | 시계열·분포 (구간 밀도·판정 분포·게이지 기록·NPS) | 도형 | 데이터 출처·축·막대/선·색 규칙 |
| `group` | 묶음 | 요소 여러 개를 하나로 옮기고 감춤 | — | 위치·크기·잘라내기(clip)·투명도 |
| `list` | 목록 | 항목 틀 하나를 데이터만큼 반복 (선곡 목록·차분 목록) | — | 항목 틀(group)·간격·스크롤·선택 강조 |

**모든 요소의 공통 속성** (`transform`): 위치(x, y)·기준점(anchor)·크기(w, h)·회전·크기 배율·투명도·보임/숨김·`z`. 단위는 **가상 해상도**(⚑ 1920×1080 기준 + 종횡비 정책)이다.

## 4. 자리 (Slot) — 엔진이 정하는 "여기에 무엇을 붙일 수 있다"

자리 = 엔진이 이름을 붙여 둔 화면 위치이자 데이터 계약. 스킨은 자리에 요소를 붙인다. 자리마다 **받는 요소 종류**와 **흘려 주는 값·사건**이 정해져 있다.
이름 규칙: `<화면>.<부분>[.<세부>]`, 레인처럼 여럿이면 `[<레인 id>]` 또는 `[*]`(모든 레인), 역할로 고를 때 `[role=scratch]`.

## 5. 값 (Value) — 엔진이 화면에 흘려 주는 데이터

이름 규칙 `<영역>.<이름>`. 화면은 **읽기만** 한다. 값은 프레임마다 판정 스레드가 게시한 스냅샷에서 읽는다(무잠금).

| 영역 | 예 |
|---|---|
| `song.*` | `title`·`artist`·`genre`·`time`(곡 시각, 화면 시계)·`progress`·`length` |
| `chart.*` | `id`·`name`·`level`·`lanes`·`bpm_now`·`bpm_min`·`bpm_max`·`notes_total` |
| `score.*` | `ex`·`combo`·`max_combo`·`counts.{pgreat,great,good,bad,poor,empty_poor}`·`fast`·`slow` |
| `gauge.*` | `kind`·`value`·`percent`·`clear_line`·`failed` |
| `input.*` | `lane[*].pressed` |
| `settings.*` | `visible_ms`·`offset_b_ms` 등 화면이 알아야 하는 설정 |
| `item.*` | 목록 항목 하나의 값 (`list` 안에서만) |
| `skin.option.*` | 스킨이 정의한 옵션 값 |

## 6. 사건 (Event)과 시계 (Clock)

- **사건**: 한 순간 일어난 일. 요소의 애니메이션·연속 그림을 시작시킨다. `judge.hit(lane, grade, err)`, `judge.miss(lane)`, `judge.empty(lane)`, `input.press(lane)`, `input.release(lane)`, `combo.break`, `gauge.clear_reached`, `session.start`, `session.end(result)`, `scene.enter`, `scene.leave`, `select.cursor_move`, `select.decide`.
- **시계**: 애니메이션이 따르는 시간. `clock.scene`(화면에 들어온 뒤), `clock.song`(곡 시각 — **화면 시계 = 청취 곡 시각 + 오프셋 B**), `clock.event`(그 사건 뒤 경과), `clock.wall`(실제 시간).
- **사건은 판정·입력 스레드가 확정한 것만** 화면에 간다(판정이 나기 전에 미리 그리지 않음). 연출 시작은 사건의 곡 시각 기준으로 늦게 받은 만큼 앞당겨 그린다(`../design/세미 게임 레이어.md` 10장과 같은 원칙).

## 7. 애니메이션 (Animation)·바인딩 (Binding)

- **바인딩**: 요소 속성 ← 값. 예: `bar.fill ← gauge.percent / 100`, `text.content ← song.title`, `image.frame ← score.counts.pgreat % 10`. 간단한 식(사칙·비교·고르기)만 허용(⚑ 식 언어 범위).
- **애니메이션**: 키프레임(시각 → 속성 값) 목록 + 시계 + 시작 사건. 예: 판정 글자 = `judge.hit` 때 0 ms 크기 1.2 → 80 ms 1.0, 300 ms 뒤 투명.
- **조건(Condition)**: 요소를 보일지 정함. 예: `score.combo >= 2`, `gauge.kind == "hard"`, `skin.option.show_bga == true`.

## 8. 스킨 (Skin)·에셋 (Asset)

| 이름 | 뜻 |
|---|---|
| **스킨** | 화면 배치 전체를 담은 묶음: 목록 파일(이름·작자·판·지원 화면·지원 레이아웃) + 화면마다 배치 + 에셋 + 스킨 옵션 정의 |
| **배치 (Layout)** | 한 화면의 층·요소·자리 연결·바인딩·애니메이션·조건 |
| **레이아웃 맞춤** | 플레이 배치는 **레인 레이아웃 서명**(예: `SC K1 … K7`)마다 따로 둘 수 있고, 없으면 레인 수·역할로 고른 일반 배치(레인을 매개변수로 늘이고 줄임) |
| **에셋** | 파일 하나: `image`·`video`·`font`·`sound`(UI 효과음). 스킨 안 상대 경로, 엔진은 내용 해시로 캐시 |
| **스킨 옵션** | 스킨이 정의하는 사용자 설정(켜기·끄기·고르기·숫자). 설정 화면에 그대로 나타나고 스킨별로 저장 (Qwilight `configure-N`과 같은 구조) |
| **기본 스킨** | 엔진에 들어 있는 스킨. 모든 자리를 채워, 사용자 스킨이 빠뜨린 자리를 메운다 |
| **곡 그래픽** | Track이 참조하는 그래픽(BGA 영상·이미지 BGA·자켓·배경). 미디어 저장소·Track 그래픽 묶음·선곡 자원(CP3 README 2-1). 스킨은 `play.bga`·`select.jacket` 같은 **곡 그래픽 자리**의 틀만 정한다 |

## 9. 미정 (⚑)

1. 가상 해상도와 종횡비 정책 (1920×1080 + 레터박스 / 기준점 늘이기).
2. 바인딩 식 언어의 범위 (선언형만 / 작은 식 / 스크립트 Lua 등).
3. 기존 스킨 형식 불러오기 (LR2·beatoraja·Qwilight) 목표 여부와 순서.
4. 층을 스킨이 더 만들 수 있게 할지.
5. 자리 목록의 4-4 이후 화면 채우기 (4-0 단계 산출물).
